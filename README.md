# EatsHere Diner

A front-end website redesign for **EatsHere Diner**, a restaurant in Silang, Cavite. Built with plain HTML, CSS, and JavaScript, it focuses on layout, visual design, and responsiveness.

> **Note:** This is a UI-only project. It has no backend and no database, so the forms are designs only and do not save or send any data. It was made before we learned PHP and databases.

## Features

- Landing page with a hero section, featured menu, and call-to-action buttons
- Full menu organized by category (silog meals, rice meals, pack meals, snacks, drinks, desserts, and more)
- About section and a footer with contact details and social links
- Reservation page with a form for personal information, date, time, number of guests, and optional notes
- Log-in page design
- Sticky navigation bar that changes style as you scroll (JavaScript `IntersectionObserver`)
- Responsive layout for desktop, tablet, and mobile

## Run Locally

No installation is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Structure


## Limitations

- Forms (reservation and log-in) do not submit or store data
- Menu items are static content written directly in HTML
- Log-in and "Create new account" are visual only
